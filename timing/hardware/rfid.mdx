If you already own an RFID timing pad, you can feed its reads straight into your
session instead of typing bibs by hand.

<Note>
  **Time2Bike identifies riders by bib number and nothing else.** There's no chip
  database to build here, no transponder list to import, and nothing to
  reconcile before the race. Whatever bib number your reader reports is the
  rider Time2Bike credits.

  Pairing a chip to a rider is handled in your reader's own software, the way you
  already do it. That's the only place it needs to happen.
</Note>

## Reading from a file (the usual way)

Best when your reader's software writes to a file on the same computer you're
timing from.

<Steps>
  <Step title="Open the RFID panel on the timing screen">
    It sits below the main finish input.
  </Step>
  <Step title="Click 'Pick CSV & watch' and choose the file your reader writes to">
    ![RFID CSV import](/images/timing/rfid-csv.png)
  </Step>
  <Step title="Leave the tab open">
    Every new line the reader writes is picked up and recorded as a finish, as
    it happens. Nothing to press.
  </Step>
</Steps>

The file needs a bib column and a time column. Anything else in it is ignored.

## Reading from another machine

If the pad is on a different computer from the one you're timing on, Time2Bike
can accept reads over the network instead. Contact support and we'll give you a
small helper program that forwards reads from your reader into the session — it
signs in with a timing link, the same as any volunteer phone.

## Things to know

<AccordionGroup>
  <Accordion title="Check the race tab before you start the watcher" icon="tag">
    Incoming reads go into whichever race tab is active when they arrive. Set it
    first.
  </Accordion>
  <Accordion title="Unknown bibs still get recorded" icon="circle-question">
    A read for a bib nobody's assigned isn't thrown away. It sits in the results
    unattached, and fills in automatically once you assign that number to a
    rider.
  </Accordion>
  <Accordion title="The watcher stops if the tab goes to the background" icon="triangle-exclamation">
    Some computers pause background tabs. Keep the timing tab in front, and if
    reads stop arriving, re-pick the file to start it again.
  </Accordion>
  <Accordion title="You can mix it with typing" icon="keyboard">
    The manual input keeps working while the watcher runs. If a chip doesn't
    read, type the bib — it's recorded the same way.
  </Accordion>
</AccordionGroup>

## You don't need any of this

An RFID pad is an option, not a requirement. Plenty of races are timed
perfectly well with two volunteers typing bib numbers into phones — that's what
the rest of this section is about.
