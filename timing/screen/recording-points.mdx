A timing crew is spread around a course: someone at the start chute, someone at
the halfway split, someone on the line. Rather than giving each of them a
different little form, **each device says where it is standing once**, and the
one big input does that job.

Same keystrokes, same chips, same digit pad. Only the meaning of **Enter**
changes.

> !!-IMAGE-NEEDED-!! — The recording-point button row above the plate input, with "Halfway" selected.

## Two places to set it

| Where | When to use it |
|---|---|
| **Above the plate box** | The quick switch during a race. Only appears when the race has more than one point — a race with just a finish line has nothing to choose |
| **Advanced timing tools → This device is timing the…** | Setting your post before the gun, or when the inline row isn't showing because this race only has a finish line. It always offers both ends, even on a race that doesn't use them, so you can set your post for the whole day |

Both do the same thing. The settings one is the reliable place to look, because
it's always there.

> !!-IMAGE-NEEDED-!! — The "This device is timing the…" card inside Advanced timing tools.

## You can pick more than one

A criterium's start and finish are the same line on the tarmac. The person
standing there checks riders out and takes their finishes, and shouldn't have to
flip a control between the two on every pass.

So **tap both ends** and the screen stops asking. Each plate is resolved by the
rider, not by you:

| The rider | What your entry records |
|---|---|
| Not on course yet | Checks them in |
| Already racing | Records their finish (or lap) |

It's the same rule an RFID mat at a shared start/finish already follows.

<Note>
  **A split can't be combined with anything.** It's a mid-course point where a
  plate read means exactly one thing — mixing it in would leave the rider's state
  choosing between two records that are both plausible. Tapping a split replaces
  whatever else was selected.
</Note>

## The buttons

Showing only the points that exist for this race:

| Point | Enter records | Appears when |
|---|---|---|
| **Start line** | A rider checking onto the course | The race checks riders in rather than mass-starting |
| **A named split** | That rider's time at that point | You've defined split points for the race |
| **Finish line** | A finish | Always |
| **Lap** | One lap for that rider | The race is in lap mode |

If a race only has a finish line, no buttons appear — there's nothing to choose.

## It's per device, and it sticks

Your choice is remembered **on your device only**. Two laptops on the same timer
are normally standing in two different places, so this is deliberately not
shared — setting yours doesn't move anyone else.

### When you switch races

You choose what happens, in the same settings card under **When I switch races**:

| Option | Use it when |
|---|---|
| **Keep me here** *(default)* | Your races share a start/finish. The finish judge is at the same arch for the 9am, the 10:30, and the juniors — set it once for the day |
| **Ask per race** | Each race has its own points, and you'd rather say explicitly every time |

Either way a **split** never carries over. Split names belong to one race, so
carrying one to the next would name a point that doesn't exist there — splits
are always remembered against their own race.

Your choice also survives a reload, so a refresh mid-race doesn't quietly put you
back on the finish line.

The inline row appears as soon as you open the race — you don't have to wait for
the start — so a marshal walking to their post can set it while there's still
time to read the screen.

<Tip>
  Set it once when you get to your post, then don't think about it again. The
  submit button and the hint text both name what you're recording, so a glance
  confirms you're still pointed at the right place.
</Tip>

## Setting up split points

Splits are defined per race by whoever runs timing. On the timing screen expand
**Advanced timing tools**, then click that race's **Lap + split points** button.

Give each split a short name your marshals will recognise — "Top of the climb",
"Halfway", "Bell lap". Those names become the buttons, and the column headings
in results.

If you use RFID, each split can also be tied to a specific mat so reads from that
mat land on that split automatically.

## Mass start vs check-in

Also set per race, in the same **Lap + split points** dialog:

- **Mass start** — the whole roster goes on course the moment you press START.
  Right for road races, XC, criteriums.
- **Check riders in** — nobody is on course until someone records them at the
  start line. Right for rolling starts and staged chutes, where knowing who
  actually left matters.

Either way, **elapsed time is measured from the gun** (or from that rider's
[wave](/timing/screen/waves)), so a late check-in never shortens somebody's run.

## A worked example

A 50 km gravel race with a timing point at the halfway aid station:

| Person | Where | They set | They do |
|---|---|---|---|
| You | Finish arch | Finish line | Type bibs as riders come in |
| Marshal | Aid station | Halfway | Type bibs as riders roll through |

Both use the same screen, and both just type numbers. The results end up with a
halfway split and a finish time per rider, and you never told either person to
use a different control.
