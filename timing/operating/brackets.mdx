Bracket sessions add a **bracket panel** on top of the operator screen for head-to-head formats (dual slalom, 4X, knockout XC).

![Bracket](/images/timing/bracket.png)

## Bracket workflow

1. After seeding (timed runs), the bracket is generated from the seeding results.
2. Each match is a **`lane_start` → `lane_finish` (×2)** pair.
3. The winner advances; the bracket diagram refreshes.
4. Repeat until the final.

You can run an entire bracket inside one session — the session covers all rounds.

## Seeding

Run a `standard` mode session first for seeding runs (timed individual runs). Finalize and publish those results, then create a `dualSlalom` session and pick the seeded riders.

Time2Bike does not currently auto-generate bracket draws from seeding results — assign matchups manually on the starter's **On deck** panel for each round.

## Operating during a match

- Starter types red + blue plates → START.
- Each finisher presses FINISH when their lane crosses.
- The bracket panel updates the match with both times and the winner.
- Long-press a match → **Mark winner** to manually override (DSQ, DNF, etc.).

## Best-of-two and other formats

For best-of-two (typical slalom rule):

1. Run match leg 1 (red on red lane).
2. Run match leg 2 (lanes swapped).
3. The reducer adds the two legs' times; lowest combined wins.

Bracket display always shows both legs and the combined time.
