Everything here is under **More actions** on the timing screen, except the
results PDF, which sits in the footer once you've finalized.

## What you can get

| Export | Contains | Works offline |
|---|---|---|
| **Results PDF** | Printable sheet for this timer — one table per race | No |
| **Selected race PDF** | Just the race you're on | No |
| **Combined event results PDF** | Every published race plus imported and manually entered results, in one document | No |
| **Print results** | The current results straight from this device | **Yes** |
| **Export CSV** | The full record of entries, with reconciled times | **Yes** |
| **Export JSON** | The same plus rider and race detail | **Yes** |
| **Export event results CSV** | Every result on the event, including ones that didn't come from live timing | No |

## The PDFs

Each includes the event name, race, date, and location, then a table per race:
place, bib, name, category, time, status. The footer records who timed it and
when the document was generated.

Before you finalize, every page is stamped **PRELIMINARY** — so a provisional
sheet can't be mistaken for a final one on a noticeboard.

You can turn that off in the PDF options. It's on by default, because an
unfinalized sheet handed to a rider really is provisional; turn it off when
you're printing a working copy for the officials' tent, where the band is just
noise on every page.

### Combined dual-slalom fields

Where categories raced as one field, the bracket prints once for the whole
field, and every rider's plate is looked up in the category they're actually
entered in.

→ [Running several categories as one field](/timing/formats/dual-slalom-event#running-several-categories-as-one-field)

### Races that score more than one result

A race set to split its scoring prints one **section per scoring group** rather
than one table for the whole field. Place restarts at 1 in each section and gaps
are measured from that section's own leader, so the sheet you pin up is the
sheet the awards run off.

- **Age-group split** → a section per bracket
- **Score men and women separately** → a section per gender
- Both on → a section per bracket and gender, headed like `40-49 · Female`

Riders with no gender on file print under **Unspecified** rather than being
folded into a real group.

→ [Splitting one race into several results](/organizers/races/race-overview#splitting-one-race-into-several-results)

You can customise what's included before generating.

<Tip>
  The **combined event results PDF** is what to post at the end of a weekend. It
  gathers every published race plus anything you imported or entered by hand, so
  nothing is missing just because it wasn't timed live.
</Tip>

## Printing with no signal

**Print results** renders from what's on your device, so it works at a trailhead
with no bars. It's the one to use when the awards are happening now and the
network isn't.

The CSV and JSON exports are the same — both come off your device.

## What the exports are for

| Situation | Use |
|---|---|
| Awards ceremony | Results PDF, or Print results if you're offline |
| Protest window | Draft PDF pinned up, protest clock starts |
| Sanctioning body | PDF — most want a document, not a link |
| Your own records | Event results CSV |
| Backing up before finalizing | Export CSV or JSON, off the device |
| Comparing two operators' records | Export CSV from each and diff them |

## Importing from elsewhere

**More actions → Import results** takes a file from another timing platform and
brings those results in. Useful when part of your weekend was timed on something
else, or when you're moving over mid-season.

Imported results appear alongside timed ones and are included in the combined
event PDF and CSV.

→ [Event imports](/organizers/events/imports)
