Time2Bike generates printable result sheets for any session — you don't have to
finalize or publish first.

## One session

Click **Download PDF** on the session. You get:

- Event name, race, date, and location at the top.
- A table per race: place, bib, name, category, time, status.
- Who timed it and when the document was generated.

If the session isn't finalized yet, every page is stamped **DRAFT**, so a
provisional sheet can never be mistaken for a final one on a noticeboard.

## The whole event

From the **Live Timing** list, click **Combined PDF** in the header. One document
covering every published session for the event — the right thing to post at the
end of a weekend.

## What it's good for

| Situation | Why the PDF |
|---|---|
| Awards ceremony | Print it, pin it up, read from it |
| Protest window | Post the draft and start the clock on protests |
| Sanctioning body | Most want a document, not a link |
| Sponsors | Something to send that won't change under them |

Everyone downloading the same PDF gets the same document, so what you print and
what a rider downloads always match.
