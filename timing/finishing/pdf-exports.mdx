title: "PDF exports"
description: "Download printable race results."
---

Time2Bike generates PDF result sheets for any session, finalized or not.

## Per-session PDF

From the session screen, click **Download PDF**. The PDF includes:

- Event + race header, date, location.
- A table per race: place, plate, name, category, time, status.
- Footer with the timing operator, generation timestamp, and a signed hash for integrity checks.

Drafts (non-finalized) are watermarked **"DRAFT"** on every page.

## Combined event PDF

From the event's Live Timing list page, click **Combined PDF** in the header. This produces a single document covering every **published** session for the event — useful for posting one results document for the whole weekend.

## When to use it

- Post-race protests and protest windows.
- Awards ceremony scoreboard.
- Sanctioning body submissions.
- Sponsor reporting.

The PDF is generated server-side and is identical for every viewer — what you see is what they see.
