The **Edit details** tab of a series lets you change:

- **Name**
- **Web address** — the `summer-gravel-cup` in `time2.bike/series/summer-gravel-cup`.
- **Description**
- **Start date** / **end date**

<Frame caption="Example screen with fictional demo data.">
  <img src="/images/organizers/series-edit.png" alt="Series editor showing the series name, web address, dates, and age-on date" />
</Frame>

<Warning>
  **Changing the web address breaks every link you've already shared.** Old
  addresses don't redirect — a link on a flyer, in an email, or in a Facebook
  post stops working the moment you save. Change it before you publicise the
  series, not after.
</Warning>

Click **Save Changes** to apply. The change takes effect straight away.

To change which events are in the series, use the **Overview** tab instead.

## Does this series run again?

A series that comes back season after season can be set up as a **recurring
event** — a shared web address, every season listed under it, and a results
archive across all of them.

Use **Does this series run again? → Schedule the next season** at the bottom of
this page. It creates next season as a draft and links the two.
