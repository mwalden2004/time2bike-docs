**Pricing → Redemptions** shows recorded discount-code uses. Use it to review
which entries or orders received a discount.

<Frame caption="Example screen with fictional demo data.">
  <img src="/images/organizers/redemptions.png" alt="Discount redemption totals and redemption history" />
</Frame>

Each row shows:

- **Code** — what was redeemed.
- **User** — the user identifier, or `Guest` when there is no account.
- **Discount** — dollars off.
- **Event** — the event identifier, when available.
- **Redeemed** — timestamp.

## Why it's separate from the codes list

- One code can have many redemptions; this is the firehose.
- Cancelling or refunding a registration does not by itself remove its
  redemption. Clearing registrations does remove associated redemptions.

Top-of-page tallies show **Total redemptions**, **Total discount given**, and
**Unique codes used**.
