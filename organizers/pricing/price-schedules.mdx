A **price schedule** is a named, reusable set of tiers you can apply to any race. Manage them at **Pricing → Schedules**.

[IMAGE: /organizations/[id]/pricing/schedules → schedule list with tier counts]

## Tier model

Each schedule has one or more **tiers**:

| Field | Purpose |
|---|---|
| **Name** | "Early bird", "Regular", "Late". |
| **Price** | Decimal. Currency is the schedule default. |
| **Valid from** | When this tier becomes active. |
| **Capacity** | Optional cap on this specific tier. Leave blank for unlimited. |

Tiers are evaluated in order; at any moment the active tier is the latest whose `validFrom` is in the past and which still has capacity.

## Create a schedule

1. Click **New schedule**.
2. Set **name**, **currency**, and add tiers with **Add tier**.
3. **Save**.

## Apply to a race

Open the race's **Pricing** tab (see [Race pricing](/organizers/races/race-pricing)). The schedule's tiers are **copied** onto the race; later edits to the template don't auto-propagate.

## Edit, clone, archive

From the schedule list:

- **Edit** — modify tiers (existing applications keep the old copy).
- **Clone** — duplicate as a starting point.
- **Archive** — hide from the picker without deleting.
