From your dashboard click **Create event**. Enter the basic info and location, then click **Create draft & add races**. You land on the new event’s **Races** page.

Select **Add description, co-hosts, or sanctioning now (optional)** on the Location step if you want to complete those settings before creating the event. You can also add them later.

## 1. Basic info

| Field | Notes |
|---|---|
| **Name** | Event title shown to riders. |
| **Discipline** | Mountain bike, road, cyclocross, gravel, BMX, track, enduro, downhill, cross-country, or other. Sets your default categories and the icon riders see. |
| **Start / end** | Local dates and times. |
| **Timezone** | Used for all rider-facing times. Defaults to America/Chicago; change it to the event’s time zone. |

## 2. Location

Venue name + street address (line 1/2, city, state, postal code, country). This powers the address line and map embed on the public page.

## Optional: Details

- **Description** — short summary for the landing page hero.
- **Website** — optional outbound link.
- **Mobile number** — event contact number. Use one intended for event use.
- **Notes** — event notes. Avoid putting confidential information in event fields.

## Optional: Advanced settings

- **Publication Status** — draft, archived, or hidden. Draft is the default. To go live, request publication from **Event setup → Settings** after setup.
- **Permit issuer / ID** — optional metadata for sanctioned races.
- **Collaborating organizations** — type another organization's web address to
  give them editing access to this event. Useful for joint promotions and
  shared series.

Required fields are listed above the action buttons while anything is missing. After creating the event, add your first race. Return to **Overview** for setup checks and links to the items that need attention.

## What's created

Creating an event gives you an empty shell: no races, no questions, no waivers, no pricing. Add those from the Event nav.
