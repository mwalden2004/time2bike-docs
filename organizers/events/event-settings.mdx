## Status

Status is a set of distinct visibilities, not a progression. Pick the one that
matches who you want to reach.

| Status | Who can open it | Registration |
|---|---|---|
| **Draft** | Authorized organization staff and Time2Bike staff can preview it. | Open to your own staff, and every entry is a free [test entry](/organizers/events/test-entries). |
| **Unlisted** | Anyone with the link. | Real, at the real price. |
| **Published** | Everyone. Listed publicly. | Real, controlled by each race's window. |
| **Archived** | Staff preview; the event is unavailable through the public event page. | Closed. |
| **Hidden** | Staff preview. | Closed. |

Publishing or listing an event requires review. Submit it from this page and
check the review status before announcing that registration is open.

### Draft

A draft is your staging area. Your organization can open the page and walk the
whole entry flow, with real prices, real waivers and a real confirmation email,
without taking money. Those entries are flagged and should be cleared before you go
live. See [Test entries](/organizers/events/test-entries).

If you switch away from **Draft** with test entries still on the event, this
screen tells you how many and links you to the tool that clears them.

### Unlisted vs hidden

These two get confused, and they're opposites:

- **Unlisted** is *shareable but not advertised*. The link works for anyone,
  registration is real and takes payment, but the event stays out of public
  Time2Bike event listings and sitemap. Use it for a link-only launch. Anyone
  can share the link; unlisted is not an invitation or access restriction.
- **Hidden** removes public access to the event page while retaining staff
  preview. It does not recall copies or exports that were already shared.

### Archived

Registration is closed and the public event page is unavailable. If you want
spectators to keep accessing an event's results, review its public page before
changing it to **Archived**.

## Permitting & sanctioning

If your event is sanctioned, set the **Permit issuer** and (optionally) **Permit ID** here. Supported issuers: `USAC`, `UCI`, `T2B`, or a `CUSTOM` issuer name you provide.

Setting a permit issuer:

- Adds a **Sanctioned** badge to the public event page.
- Enables the **License** check on the registration **Review & pay** step. See
  [Rider licenses](/riders/registering/licenses).
- Enables the **Licenses** tab in the event admin for tracking one-day filings.
  See [Licenses](/organizers/events/licenses).

Selecting UCI disables one-day license purchase in Time2Bike. Confirm the
license requirements for your event with the relevant sanctioning body.

## Collaborating organizations

You can give another organization editing access to this event by entering
their **web address**, the `socalmtb` in `time2.bike/socalmtb`. They appear in
the list below; click the **×** to take it away again.

Collaborators can edit everything except settings/billing-level fields. Useful for:

- A series host running an event the host org will physically run.
- Two clubs co-presenting a race.
- A timing company managing race-day data on your behalf.

Only the owning org (the one that created the event) shows in the **Event owner** label; collaborators see the event in their own dashboard alongside their owned events.
