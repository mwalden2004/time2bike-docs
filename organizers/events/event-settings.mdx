**Settings** under any event controls publication state and inter-org access.

[IMAGE: /organizations/[id]/events/[eventId]/settings → form with status select and collaborator chips]

## Status

- **Draft** — visible only to org members. Default for new events.
- **Published** — listed publicly; registration controlled by each race's window.
- **Archived** — keeps results live but hides from upcoming-event lists.
- **Hidden** — public page returns 404; useful for paused events.

Changing status is instant.

## Collaborating organizations

You can grant another org edit access on this event by entering their **slug**. They appear in the chip list; remove the **×** to revoke.

Collaborators can edit everything except settings/billing-level fields. Useful for:

- A series host running an event the host org will physically run.
- Two clubs co-presenting a race.
- A timing company managing race-day data on your behalf.

Only the owning org (the one that created the event) shows in the **Event owner** label; collaborators see the event in their own dashboard alongside their owned events.
