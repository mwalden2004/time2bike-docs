The **Event overview** at `/organizations/[id]/events/[eventId]` is your dashboard for one event.

[IMAGE: /organizations/[id]/events/[eventId] → top of event overview with stat cards and status pill]

## Header

- Event **name**, **status** (`draft` / `published` / `archived` / `hidden`).
- **Start date** with countdown ("12 days to go").
- Venue and city.
- **View public page** opens the rider-facing event page in a new tab.

## Stat cards

- **Total revenue** (gross paid).
- **Total registrations**.
- **Average registration value**.
- **Days until event**.
- **Registrations today**.

## Race breakdown

A row per race in the event with **registered / capacity** and a progress bar. Click a row to jump to the race page.

[IMAGE: /organizations/[id]/events/[eventId] → race breakdown rows with capacity bars]

## Recent registrations

The last eight registrations across all races, with name, race/category, amount paid, status, and time. Click any row to open the registration editor (see [Editing and refunds](/organizers/registrations/editing-and-refunds)).

## Side rail

- **Quick actions** — create race, edit landing page, manage bibs, open analytics.
- **Event details** — discipline, timezone, permit, collaborators.
