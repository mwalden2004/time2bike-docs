**Race → Results** is for organizers who time manually or who want to publish results without using [Live Timing](/timing/overview).

## Three input modes

Click **Add result** or **Bulk upload**, then choose **Single**, **Line by Line**, or **CSV File**.

<Frame caption="Example screen with fictional demo data.">
  <img src="/images/organizers/race-result-input.png" alt="Result entry dialog with Single, Line by Line, and CSV File input modes" />
</Frame>

### Single rider

1. Search for the rider by name.
2. Enter their **Finish time (hh:mm:ss)** or pick a **status** (`dnf`, `dns`).
3. Save.

### Line by Line

Paste one result per line using `Name, hh:mm:ss`, with an optional status:

```text
Rider 101, 01:02:00
Rider 102, 01:02:34
Rider 103, 00:00:00, dnf
```

Click **Upload Results** to add the rows.

### CSV File

Upload a `.csv` or `.txt` file with columns in this order:

```text
Name, Time, Bib, Status
Rider 101, 01:02:00, 101, ok
Rider 102, 01:02:34, 102, ok
```

**Bib** and **Status** are optional. A header row beginning with **Name** is
supported.

## Split results

If the race is set to score age brackets or men and women separately, results
are grouped accordingly everywhere they appear — this table, live results, the
public results page, and the printed PDF. Each group gets its own placement and
its own time gaps.

You don't enter anything differently. Everyone is one race with one set of
finish times; the split only changes how they're scored and displayed.

→ [Splitting one race into several results](/organizers/races/race-overview#splitting-one-race-into-several-results)

## Display & publish

Results are **draft** until you click **Publish**. Drafts are visible only to
your own organization; once published they appear on your public event page.
