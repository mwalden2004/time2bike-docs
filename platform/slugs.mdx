Every organization, event, and series gets its own web address: the
`mountain-bike-club` part of `time2.bike/mountain-bike-club`. You pick it when
you create the thing, and it's what you'll be putting on flyers and in emails.

## The rules

- Lowercase letters, numbers, and hyphens only.
- It can't start or end with a hyphen.
- Every address is unique across all of Time2Bike. Organizations, events,
  series, teams, leagues and recurring events all draw from the same pool, so if
  a cycling club already has `spring-classic`, nobody else can take it.

If the one you want is taken, the form tells you and suggests something close.

## Where each address goes

| Address | What's there |
|---|---|
| `time2.bike/demo-cycling` | The organization's public page |
| `time2.bike/demo-cycling/store` | Their merch store |
| `time2.bike/events/spring-classic` | An event's page — or, if the race runs more than once, the race itself, showing whichever running is current |
| `time2.bike/events/spring-classic/register` | Signing up for that event |
| `time2.bike/events/spring-classic/results` | That event's results — live during the race, official once published |
| `time2.bike/events/spring-classic/2025` | One running of a recurring event |
| `time2.bike/series/summer-gravel-cup` | A series page |

Rider profiles work differently: they're at `time2.bike/profiles/…` followed by
an ID Time2Bike generates, not a name you choose.

## Changing one

You can change an organization, event, or series address from its settings page
at any time.

<Warning>
  **Old addresses don't redirect.** Every link anyone has already shared, on a
  flyer, in an email or on Facebook, stops working the moment you change it.

  If you have to change one, do it before you publicise anything, and go back
  through your own emails and posts for the old link afterwards.
</Warning>

## Reusing an address across occurrences

A recurring event provides a reusable address for the current occurrence, with
a dated address for each occurrence. Keep that recurring event and its address
in place if you plan to reuse the link in future seasons.

→ [Recurring events](/organizers/events/recurring-events)

## Words you can't use

A handful of words are part of Time2Bike's own addresses and can't be taken:
`auth`, `dashboard`, `account`, `organizations`, `events`, `series`,
`profiles`, `timing`, and a few others. The form rejects them and offers an
alternative.
