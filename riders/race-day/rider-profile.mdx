A **rider profile** is the racing identity used on the start list and in
results. You can have many profiles on one account — yourself, a partner,
your kids — so a parent can manage a whole family from one inbox.

Your profile management page requires sign-in and appropriate access; rider
names and race details may also appear in public start lists and results. Open
the profiles you can access from
[time2.bike/profiles](https://time2.bike/profiles).

## Profile page

The profile page shows:

- **Name and age** (calculated from birthday)
- **Hometown** and competition gender
- **Race history & payments** — linked registrations and payment details
- **Season plates**, when assigned
- An **Edit profile** button (visible only if you can edit) and a
  **Sharing** button (visible only if you're the owner)

## Editing a profile

Click **Edit profile**. You can update:

- First / last name
- Date of birth
- Gender
- Address, emergency contact
- Team affiliation
- Any optional fields the organizer asks for

Saving updates the stored rider profile. Existing registrations and published
results can contain separately recorded details; contact the organizer if a
past entry or result also needs correcting.

Only the **owner** of a profile or someone with **editor** / **manager**
access can edit. If you don't have permission, the Edit button is hidden.

## Sharing a profile

Open the profile and use its **Sharing** page to let someone else view or
manage that rider. Common cases:

- A parent grants the other parent **manager** access to their kid.
- A team captain grants a coach **viewer** access to teammates.

### Roles

| Role | Can view profile and history | Can edit profile | Can manage sharing |
| --- | --- | --- | --- |
| **viewer** | ✅ | – | – |
| **editor** | ✅ | ✅ | – |
| **manager** | ✅ | ✅ | – |
| **owner** | ✅ | ✅ | ✅ |

The sharing controls do not let other managers revoke the profile owner's access.
Shared access does not establish authority to sign a waiver or act as a guardian.

## Your profiles list

All of your profiles live at `time2.bike/profiles`. From there you can:

- Open any profile
- Create a new one with **New profile**
- See which profiles are yours and which have been shared with you
